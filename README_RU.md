# 🔓 CMP 100-100 UNLOCK


**12 ГиБ на Linux · Gen2 и x16 — продолжим вместе**

Привет, я **6Robert123** 👋 Взял на Авито NVIDIA CMP 100-100 (**GP100 / Pascal**) примерно за 2200 ₽. Это майнинговая карта, у которой из коробки доступно 6 ГиБ, и мне стало интересно, на что она способна. Покопался как следует, и теперь на Linux она стартует с **12288 МиБ, объявленными драйвером NVIDIA**. Архивные измерения — по 1 ноября 2026 года, офлайн-ревизия многокарточной обёртки — 2 ноября 2026 года.

А вот с PCIe я пока воюю: **Gen2 и фактический x16 пока не получены.** Четвёртый HBM site и физическая плотность памяти тоже не установлены. Если разбираетесь в PCIe или HBM на Pascal/GP100, буду очень рад помощи.

## Быстрый старт (30 секунд)

- **Что делает:** инициализирует NVIDIA CMP 100-100 (GP100) на Linux так, что драйвер показывает 12288 МиБ вместо 6144 МиБ.
- **Нужно:** Linux x86_64, glibc >=2.38, драйвер NVIDIA, стандартные PCI-утилиты, Python 3.8+.
- **Запуск:**

```sh
bash unlock/cmp100-12gb.sh --help
sudo bash unlock/cmp100-12gb.sh --check
sudo bash unlock/cmp100-12gb.sh --apply
```

Gen2 и фактический x16 не получены. Перед `--apply` прочитайте требования в [unlock/README.md](unlock/README.md).

## Один sh: несколько CMP, смешанный стенд, автозапуск

[Полная инструкция](unlock/README.md). Внутри `.sh` находятся Python-контроллер и закреплённый helper. Требуются Linux x86_64, Python 3.8+, glibc ≥2.38, драйвер NVIDIA и обычные PCI-инструменты.

```sh
bash unlock/cmp100-12gb.sh --help
sudo bash unlock/cmp100-12gb.sh --check
# Меняет состояние выбранных CMP:
sudo bash unlock/cmp100-12gb.sh --apply
# Только устанавливает автозапуск на следующую загрузку:
sudo bash unlock/cmp100-12gb.sh --install-boot
```

Выбираются все CMP `10de:15c2` либо явно заданные BDF. Наличие P100, других NVIDIA и AMD допускается. Общий модуль NVIDIA не выгружается; reset/helper и адресные записи направляются только выбранным CMP. Общий reset-мост или занятые/неоднозначные GPU-клиенты означают отказ. Скрипт не останавливает чужие задачи.

При `--boot` отсутствующий NVIDIA core может загрузиться один раз и штатно привязать ранее непривязанные NVIDIA-карты. Это отличается от прямого reset или запуска helper на P100; уже существующие привязки других карт должны сохраниться.

**2 ноября 2026 горячий `--apply` успешно проверен на двух CMP: обе перешли с 6144 на 12288 МиБ, код 0.** [SHA скрипта, первичные логи, исправленный отказ noexec и границы проверки](validation/hardware_20261102/README.md). Смешанный стенд с другими NVIDIA и холодный автозапуск на железе пока не проверены. Старый серверный автозапуск работал, но использовал другую последовательность с общей выгрузкой драйвера. Исходник встроенного helper теперь опубликован: [`gp100_cfg1_race_optfbio.c`](unlock/historical/gp100_cfg1_race_optfbio.c). Функции, константы и строки вывода совпадают с бинарником; собрать самому: `gcc -O2 -o gp100_cfg1_race gp100_cfg1_race_optfbio.c`. Побайтовое совпадение требует исходного компилятора (GCC 13.3, Ubuntu 24.04). Ранний `.legacy.c` — другая реализация.
